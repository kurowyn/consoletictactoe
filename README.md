# consoletictactoe
The paper-and-pencil game tictactoe, playable through the terminal, written in the C programming language.
Note that currently only multiplayer mode is supported. Solo games coming soon.

# Basic usage:
```
git clone -b consoletictactoe-version-0.2 https://github.com/kurowyn/consoletictactoe
cd consoletictactoe
make compile
./cttt
```
Dependencies: Just the standard C library, and a C compiler. The one used here is GCC, although you can use any other compiler to your liking,
by modifying the CC variable in the Makefile.
